# Biological Open Questions

These are deliberately unresolved. Do not solve them by importing familiar software patterns.

## 1. Locus birth

What biological analogue should determine creation of a novel computational locus?

Candidate biological constraints to study:
- receptive-field overlap
- coincidence detection
- dendritic branch locality
- Hebbian/co-activity-driven assembly formation
- sparse allocation and excitability bias

Do not assign semantic IDs first and call that locus formation.

## 2. Context binding

How should context become physically attached to a trace/ensemble?

Candidate mechanisms:
- shared dendritic/compartmental locality
- hippocampal index-like co-activation
- temporal coincidence windows
- oscillatory phase relationships

A string-valued `contextId` alone is not an answer.

## 3. Consolidation eligibility

Which lower-layer events earn a temporary tag?

Need experiments separating:
- high amplitude but one-shot activation
- repeated weak activation
- successful prediction
- novelty
- reward/modulation
- context reinstatement
- survival under interference

## 4. Replay selection

How does the system choose what reactivates during quiet wake/sleep without a central scheduler selecting memories by semantic name?

Need local selection rules driven by residual state, recency, unfinished competition, and network dynamics.

## 5. Systems consolidation

If a hippocampal-like fast index and cortical-like slow representation are modeled, determine whether C-phi-plus needs distinct dynamical regions rather than separate software storage systems.

## 6. Forgetting

Separate at least:
- access failure
- inhibition
- dormancy
- weakening
- overwriting/interference
- true structural loss

Do not collapse all of these into deletion.

## 7. Reconsolidation

Retrieved durable memories in biology can become labile and be modified. Determine how retrieval temporarily reopens plasticity without destroying the durable trace.

## 8. Opponent coding

Determine which quantities should be represented by:
- opposing populations
- inhibitory interneuron pathways
- signed higher-layer projections
- synaptic strengthening/weakening

Do not assume one representation fits every biological variable.

## 9. Timescales

C-phi-plus ticks are logical. Biological modeling needs explicit mappings among:
- membrane/synaptic dynamics
- gamma/theta-scale coordination
- working-memory persistence
- minutes/hours tagging windows
- sleep-cycle consolidation
- days/months systems consolidation

Do not force every layer onto one global tick rate.

## 10. Phi specificity

The golden ratio must be tested as a dynamical parameter/invariant, not assumed because it is aesthetically or mathematically attractive.

Where phi-derived values appear, perturb them independently and measure whether biological target behaviors degrade.

The architecture may discover that phi governs some layers but not others. Preserve that result if it occurs.
